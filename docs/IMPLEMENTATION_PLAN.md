# 拾录（ShiLu）项目实施步骤

## 1. 文档目的

这份文档是拾录的实际开发顺序。每一步都有明确的目标、产出和验收标准，完成后再进入下一步。前 7 步可以形成一个不依赖外部 AI 的可用本地资料库，后 3 步加入 OCR、视觉模型和文案润色。

## 2. 最终交付范围

完成后，Windows 用户可以：

1. 把一张或多张截图导入软件。
2. 使用本地 OCR 或配置的大模型识别图片内容。
3. 编辑标题、正文、链接、标签、来源和个人备注。
4. 让大模型生成整理稿或润色稿，并在替换前进行对比。
5. 将资料保存为独立 Markdown 文件夹。
6. 通过关键词搜索已保存资料。
7. 使用 Windows EXE 安装包安装和运行软件。

## 3. 实施原则

- 先保证资料不会丢失，再增加 AI 能力。
- 每一步都保留可运行版本，不把多个大功能堆到最后才验证。
- Markdown 和图片目录是真实数据，搜索缓存可以重建。
- AI 只生成建议，用户确认后才覆盖最终正文。
- 不把 Telegram、小红书、知乎、抖音等平台接入放进第一版主流程。

## 4. 十步实施计划

### 第 1 步：建立 Windows 桌面项目

**目标**：创建可以在 Windows 上启动的 Tauri 项目。

**开发内容**：

- 初始化 Tauri 2、Vue 3、TypeScript、Vite 项目。
- 配置 Rust、Node.js、WebView2 和开发命令。
- 设置应用名称、窗口尺寸、应用图标和基础权限。
- 建立 `src/`、`src-tauri/`、`docs/` 的项目结构。

**产出物**：可以启动的开发版窗口、基础项目配置、Windows 构建命令。

**完成标准**：执行开发命令后能打开拾录窗口；执行前端构建命令无类型错误和构建错误。

**前置依赖**：无。

### 第 2 步：搭建软件外壳与导航

**目标**：让软件具备稳定的桌面工作台结构。

**开发内容**：

- 实现可折叠侧边栏。
- 实现顶部栏、搜索入口、主题切换和设置入口。
- 建立总览、资料库、新建资料、设置页面路由。
- 加入页面进入、按钮悬停、侧栏折叠和加载状态动画。
- 按原型图完成浅色主题，预留深色主题变量。

**产出物**：可点击的基础界面和页面空状态。

**完成标准**：页面之间可以跳转；侧栏折叠后内容区正确展开；窗口缩放时无明显重叠。

**前置依赖**：第 1 步。

### 第 3 步：实现本地资料库和目录管理

**目标**：建立不依赖数据库的真实文件存储。

**开发内容**：

- 首次启动时选择或创建资料库目录。
- 按规则创建 `articles/<article-id>/` 目录。
- 实现 `index.md`、`images/`、`raw/`、`versions/` 的创建和读取。
- 实现资料重命名、移动到回收站和恢复。
- 用 JSON 保存资料库路径和界面设置。

**产出物**：文件系统存储服务、目录选择界面、资料库初始化流程。

**完成标准**：创建一条测试资料后，资源管理器中能看到正确目录；关闭并重启软件后仍能读取该资料。

**前置依赖**：第 1 步。

### 第 4 步：实现截图导入与素材管理

**目标**：让用户可以方便地把截图放进一条资料。

**开发内容**：

- 支持拖拽文件和系统文件选择器。
- 支持 PNG、JPG、JPEG、WEBP 等常见图片格式。
- 支持多张图片导入、排序、删除和追加。
- 显示缩略图、文件名、尺寸和文件大小。
- 将图片复制到当前资料的 `images/` 目录。

**产出物**：截图导入页、图片队列组件、图片文件服务。

**完成标准**：一次导入多张图片后顺序正确；删除或排序后重新打开资料仍保持结果；原始图片不被修改。

**前置依赖**：第 2、3 步。

### 第 5 步：实现文章编辑和 Markdown 保存

**目标**：让用户可以手动完成一篇资料。

**开发内容**：

- 实现标题、正文、摘要、来源、链接、标签和备注字段。
- 实现 Markdown 编辑器和预览模式。
- 支持自动保存草稿和手动保存。
- 按 `DATA_SPEC.md` 生成 YAML Front Matter。
- 处理 Windows 路径、特殊字符和非法文件名。

**产出物**：文章编辑页、Markdown 读写服务、保存提示和未保存状态。

**完成标准**：不配置任何 API Key，用户也能从导入图片开始手动写完并保存一篇资料；生成的 Markdown 能被普通编辑器打开。

**前置依赖**：第 3、4 步。

### 第 6 步：实现资料列表、详情和关键词搜索

**目标**：让用户可以找回已经保存的内容。

**开发内容**：

- 扫描资料库并生成资料列表。
- 显示标题、摘要、标签、来源、更新时间和缩略图。
- 支持标题、正文、标签、来源、链接的关键词搜索。
- 支持按更新时间、创建时间和标题排序。
- 生成并重建 `search-index.json` 缓存。
- 缓存损坏时自动从 Markdown 重建。

**产出物**：资料库页面、详情页面、搜索索引服务。

**完成标准**：重启软件后搜索结果正确；手动修改 Markdown 后可以重建索引；搜索缓存删除后软件仍能恢复工作。

**前置依赖**：第 5 步。

### 第 7 步：接入本地 OCR

**目标**：不使用外部 API Key 也能从图片提取文字。

**开发内容**：

- 选择并集成本地 OCR 引擎，优先支持中文和英文。
- 将多张图片的 OCR 结果按图片顺序合并。
- 保存原始结果到 `raw/ocr.txt`。
- 在编辑页提供“插入正文”和“仅保存原文”两种操作。
- 显示 OCR 进行中、成功、失败和重试状态。

**产出物**：本地 OCR 服务、识别状态组件、原始文本查看器。

**完成标准**：断网时仍能识别测试图片；识别结果可以编辑；OCR 失败不会影响原图和已有正文。

**前置依赖**：第 4、5 步。

### 第 8 步：接入视觉大模型和模型设置

**目标**：让模型理解截图内容并生成结构化草稿。

**开发内容**：

- 实现服务地址、模型名称和 API Key 设置。
- 使用 Windows DPAPI 或 Tauri Stronghold 加密保存 Key。
- 适配 OpenAI 兼容的视觉接口，保留后续适配其他服务的接口层。
- 将多张图片、OCR 文本和用户上下文发送给模型。
- 要求模型返回标题、摘要、正文、来源、链接候选和标签字段。
- 保存模型原始结果到 `raw/ai-draft.json`。

**产出物**：模型设置页、连接测试、视觉识别服务、结构化结果校验。

**完成标准**：输入有效配置后能生成草稿；Key 只显示掩码；接口失败、超时或返回格式错误时，原图和 OCR 文本仍然保留。

**前置依赖**：第 7 步。

### 第 9 步：实现 AI 润色和人工确认

**目标**：让模型帮助整理文案，同时保留用户控制权。

**开发内容**：

- 实现轻度润色、整理成笔记、改写成文章三种模式。
- 显示原文和建议稿的并排对比。
- 高亮建议稿的文字变化。
- 支持复制建议稿、替换正文和取消操作。
- 明确要求模型不虚构事实、链接、作者和功能。
- 用户确认后才更新 `index.md`，并按设置保存历史版本。

**产出物**：AI 润色抽屉、对比视图、确认保存流程、版本保存逻辑。

**完成标准**：用户可以拒绝建议稿；取消操作不会改变正文；确认替换后可以在历史版本中找到替换前内容。

**前置依赖**：第 8 步。

### 第 10 步：测试、打包和第一版发布

**目标**：把开发版变成可安装、可使用的 Windows 软件。

**开发内容**：

- 完成资料创建、图片导入、OCR、AI 识别、编辑、搜索和恢复测试。
- 测试无 Key、错误 Key、断网、接口超时、磁盘空间不足等情况。
- 检查窗口缩放、中文文本、长标题、超长正文和大量图片。
- 优化加载提示、错误信息和关键动画。
- 生成 Windows NSIS 安装包。
- 编写安装、升级、备份和常见问题说明。

**产出物**：Windows `.exe` 安装包、版本说明、用户使用说明和最终验收记录。

**完成标准**：在一台没有开发环境的 Windows 电脑上安装后可以启动；核心流程完整走通；资料目录可以独立备份和迁移。

**前置依赖**：第 1 至第 9 步。

## 5. 里程碑

### 里程碑 A：能保存资料

完成第 1 至第 5 步。此时已经可以导入截图、手动编辑文章并保存为 Markdown。

### 里程碑 B：能找回资料

完成第 6 步。此时已经具备稳定的资料列表、详情和搜索能力。

### 里程碑 C：能自动整理

完成第 7 至第 9 步。此时 OCR、视觉识别和润色都可以使用，但用户仍然掌握最终保存权。

### 里程碑 D：可以交付

完成第 10 步。此时生成正式 Windows 安装包，达到第一版发布标准。

## 6. 每一步的提交要求

每完成一步，都需要留下：

- 一句 Git Summary，说明本步完成了什么。
- 一段 Git Description，用大白话说明用户获得了什么能力。
- 运行过的验证命令和结果。
- 如果有未完成内容，记录在下一步的待办中。

## 7. 第一版完成后的后续步骤

第一版稳定后，再考虑以下扩展：

- 批量导入、批量识别和重复资料提示。
- 相似内容搜索和语义搜索。
- Markdown 版本管理、回收站和备份向导。
- 小红书、知乎、抖音的专用文案生成。
- 仅在平台提供官方授权能力时接入自动发布。
- Telegram 收藏夹连接和历史消息导入。
