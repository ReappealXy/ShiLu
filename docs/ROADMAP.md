# 拾录开发路线

实际开发请按 [IMPLEMENTATION_PLAN.md](./IMPLEMENTATION_PLAN.md) 的十个步骤执行；本文件只保留阶段路线和后续方向。

## Phase 0：文档与原型

- 固化产品流程、文件格式、接口边界和视觉规范。
- 完成主页面产品原型图。

## Phase 1：MVP 本地资料库

- Tauri Windows 壳、资料库选择和文件夹读写。
- 图片导入、Markdown 编辑、保存和关键词搜索。
- 原图、OCR、草稿和最终正文的分层保存。

## Phase 2：AI 整理

- 本地 OCR。
- OpenAI 兼容视觉接口。
- 结构化草稿、三种润色模式、原稿与建议稿对比。
- Key 加密、连接测试、超时和错误恢复。

## Phase 3：效率与质量

- 批量导入和批量识别。
- 重复图片与相似资料提示。
- 搜索索引优化、导出和备份。
- Markdown 版本历史和回收站。

## Phase 4：内容分发预留

- 平台专用文案生成器。
- 图片裁切、封面和平台格式检查。
- 只接入有官方授权能力的平台发布接口；其他平台提供复制和导出。
