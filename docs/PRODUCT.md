# 拾录（ShiLu）产品开发文档

## 1. 产品定义

拾录是一款只支持 Windows 的个人资料收集与内容整理桌面软件。用户把 Telegram、网页、聊天记录或其他来源的截图导入软件，先由 OCR 或视觉模型提取信息，再由用户编辑、补充链接和图片，最后保存为一条独立的 Markdown 资料。

产品的核心承诺是：任何值得保存的内容，都能在几分钟内从截图变成可搜索、可编辑、可迁移、可供 AI 阅读的个人资料。

## 2. MVP 范围

### 必须实现

- Windows 桌面 EXE，支持 Windows 10 及以上 64 位系统。
- 新建资料：拖入或选择一张/多张图片。
- 图片预览、排序、删除和追加。
- 本地 OCR：无模型 Key 时也能提取图片中的文字。
- 可选视觉模型：识别图文结构、生成标题、摘要、正文、链接候选和标签。
- 文章编辑：标题、正文、来源、链接、标签、个人备注。
- 轻度润色、整理成笔记、改写成文章三种 AI 操作。
- 确认保存为“一条资料一个文件夹”。
- 按标题、正文、标签、来源和链接进行关键词搜索。
- 原图、原始识别文本、最终文章分开保留。
- 设置模型服务地址、模型名称和 API Key；Key 本地加密保存。

### 暂不实现

- Telegram 自动登录和历史消息同步。
- 小红书、知乎、抖音等平台的自动发布。
- 云端账号体系和多人协作。
- 依赖数据库才能运行的功能。

## 3. 用户主流程

```text
拖入截图
  -> 预览并调整顺序
  -> 本地 OCR 或视觉模型识别
  -> 生成可编辑草稿
  -> 用户补充链接、图片、标签和备注
  -> 选择可选的润色方式
  -> 预览变更
  -> 确认保存
  -> 资料进入本地搜索库
```

## 4. 文章字段

| 字段 | 必填 | 用途 |
| --- | --- | --- |
| title | 是 | 资料标题 |
| content | 是 | 用户确认后的正文 |
| summary | 否 | 摘要 |
| source | 否 | 来源平台、频道或作者 |
| links | 否 | 用户补充或模型识别出的链接 |
| tags | 否 | 分类和搜索 |
| notes | 否 | 用户自己的补充 |
| created_at | 是 | 创建时间 |
| updated_at | 是 | 最后修改时间 |
| images | 否 | 与文章关联的图片 |
| ai_meta | 否 | 模型、识别时间和原始结果摘要 |

## 5. 验收标准

- 用户不配置 API Key 也能创建资料、保存图片、编辑 Markdown 和搜索。
- 配置一个兼容 OpenAI Chat Completions 的视觉模型后，能从多张截图生成可编辑草稿。
- 识别结果出现错误时，用户可以在保存前修改；原图永远保留。
- 每条资料都能单独复制、备份和用其他 Markdown 工具打开。
- 软件关闭并重新打开后，已保存的资料、搜索结果和设置仍然可用。
- AI 请求失败、超时或 Key 错误时，资料不会丢失，界面给出可理解的错误信息。
