# 拾录 UI 与交互设计文档

## 1. 参考项目观察

本项目参考了 `QzoneArchive-fix` 的公开代码，仅借鉴交互模式和视觉原则，不复制代码、图标、名称或品牌资产。它的有效做法包括：

- 左侧可折叠导航，收起后保留图标，主工作区平滑让位。
- 顶部固定栏显示页面标题、主题切换和账户/设置入口。
- 浅色主题以冷白和浅蓝灰为主，蓝色只用于主操作、选中状态和进度。
- 内容采用圆角较小的卡片和清晰的边框，阴影很轻，适合长时间使用。
- 卡片悬停有轻微上浮，页面切换使用短距离淡入和位移。
- 加载、成功、警告、错误使用统一颜色和状态标签，用户能快速判断任务进度。
- 移动端采用底部导航；拾录虽然只做 Windows，但可保留响应式布局，方便未来预览或窄窗口使用。

## 2. 拾录视觉方向

- 产品气质：安静、清楚、有编辑感，像一个桌面资料工作台。
- 主色：`#286BFF`；成功：`#1FA774`；警告：`#E99A26`；错误：`#D95757`。
- 背景：`#F4F7FB`；面板：`#FFFFFF`；边框：`#E3E9F2`；正文：`#172033`；辅助文字：`#6B7688`。
- 圆角：按钮 10px，内容面板 14px，弹窗 18px。
- 字体：系统中文字体优先，英文使用 Inter 或系统无衬线字体。
- 动画时长：按钮反馈 120-160ms，面板进入 180-240ms，拖拽排序 200ms 左右。

## 3. 页面原型范围

1. **资料总览**：资料数量、最近编辑、标签概览、搜索框和新建资料按钮。
2. **导入与识别**：拖拽区、图片缩略图队列、识别方式、本次任务状态。
3. **文章编辑**：左侧字段和正文编辑器，右侧图片、链接、识别原文与 AI 操作。
4. **保存确认**：显示将要生成的目录、Markdown 预览、图片清单和版本选项。
5. **设置**：资料库目录、模型地址、模型名称、Key 掩码、连接测试和主题。
6. **资料详情**：文章阅读、图片查看、打开文件夹、编辑和历史版本入口。

## 4. 关键交互

- 新建资料按钮点击后展开导入面板，面板从右侧滑入，背景轻微变暗。
- 图片拖入后缩略图以顺序动画进入队列；拖动时显示蓝色插入线。
- 识别按钮按下后变为进度状态，显示“正在读取第 n 张图片”，禁止重复提交。
- AI 生成草稿后，编辑器顶部显示“待确认”标签；用户修改后标签变为“已编辑”。
- 点击润色打开左右对比抽屉；左侧原文只读，右侧为可编辑建议稿，用户可选择替换或复制。
- 保存成功后显示资料目录路径，并提供“打开文件夹”和“继续新建”两个动作。
- 所有破坏性动作先使用确认弹窗；取消操作不丢失草稿。

## 5. 可访问性和窗口行为

- 所有图标按钮都有文字 Tooltip 和键盘焦点样式。
- 编辑器支持 `Ctrl+S` 保存、`Ctrl+K` 聚焦搜索、`Ctrl+Enter` 确认 AI 结果。
- 最小窗口宽度 1100px，编辑页面在 1280px 以上显示三栏，窄窗口自动变成两栏。
- 拖拽、加载、失败和完成状态必须同时提供文字，不只依赖颜色。
