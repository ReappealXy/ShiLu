# 文章工作流与交互改造

本次是在原 Vue + Tauri 桌面软件上局部重构，不替换框架，也不增加数据库。

## 1. 导航与文章生命周期

弧形导航提供总览、新建资料、资料库、归档箱、设置五个入口。滚轮定位后直接切页，鼠标可以点击；折叠模式使用紧凑的五个图标。三个新建步骤只出现在文章流程内部，内部临时状态不作为草稿箱展示。

| 状态 | 展示位置 | 可执行操作 |
| --- | --- | --- |
| draft | 内部临时状态 | OCR 失败重试和流程保护，不在用户导航中展示 |
| active | 资料库 | 搜索、编辑、归档 |
| archived | 归档箱 | 搜索、打开、恢复到资料库 |

归档是可恢复的收纳状态，不是删除或回收站。已有文章缺少状态字段时仍显示在资料库。

## 2. 新建流程

1. 添加截图：粘贴、选图、拖入、排序和移除。
2. 补充信息：输入标题、可选来源链接；可返回第一步。
3. 点击识别并编辑：保存临时状态，使用已配置的 OCR 模型识别指定源图；成功后把结果写入同一篇资料正文，进入统一编辑器。

保存前记录已导入图片的相对路径，重复保存不会重复导入。OCR 失败仍留在第二步；识别成功但正文保存失败时，当前页面保留结果，重试先保存结果，不重复识别。用户界面不提供草稿箱。

## 3. 统一编辑器

- 同一份正文支持 Markdown 源码、编辑/预览对照及预览模式。
- 使用 Markdown 解析器支持标题、列表、表格、代码、引用、链接和本地图片；输出经过 HTML 清理。
- 光标处粘贴图片或点击配图工具，把图片写入当前文章 images/，再插入相对 Markdown 引用。普通文字粘贴正常。
- 润色请求读取点击时的最新正文，结果可编辑和预览；点击采用才替换正文。请求后正文已有变化时，需重新润色；缺少原配图引用时提示补回后采用。
- 正文自动保存，手动 Ctrl + S 提供结果反馈。保存请求串行执行，旧请求完成不会把较新的输入标成已保存。
- 页面切换先保存；图片写入、保存失败或待确认的润色结果会明确提示，不静默丢弃。

## 4. 模型设置

OCR 和润色各自维护获取列表、测试、保存三种操作的状态。操作使用点击时的表单快照，不强制先保存，不会改写另一张配置卡。地址或 Key 修改后，迟到的旧模型列表不再应用。

OCR 测试使用内置文字图片检查实际识图响应；润色测试使用样例文字，成功展示模型返回。接口失败、空列表、空响应、认证错误等均显示可重试的反馈。

## 5. 验证顺序

1. 临时资料库测试状态转换、源图顺序、旧文件兼容和正文往返。
2. 本地 HTTP 模拟服务测试模型列表与请求内容，使用假 Key。
3. 外部 Chrome 点击回归：收集、失败重试、正文纠错、配图预览、润色确认、归档恢复、双模型并发、小窗口和折叠导航。
4. 前端类型检查、Rust 测试与格式检查，最后构建 Windows 安装包。

不使用 Codex 内置浏览器，不操作用户真实资料库，测试结果和限制记录在 IMPLEMENTATION_LOG.md。
